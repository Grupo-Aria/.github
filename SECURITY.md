# Política de segurança

Encontrou uma vulnerabilidade em algum sistema do ecossistema Aria? **Não abra uma issue pública.**

Reporte de forma privada pela aba **Security → Report a vulnerability** do repositório afetado, ou entre em contato com os administradores da organização.

Responderemos o mais rápido possível e manteremos você informado sobre a correção.
